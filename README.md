# UNICAH – Interfaz móvil (maqueta)

Maqueta estática de la interfaz móvil de la plataforma de registro de la UNICAH (`registro.app.unicah.net`), hecha con HTML y CSS puros.

## Pantallas

- **`index.html`** – Inicio: accesos rápidos (Registro / Gestiones), banner informativo y barra de navegación inferior.
- **`registro.html`** – Sección de registro: menú con Prematrícula, Mis clases, Oferta académica, Gestiones, Servicios académicos, Estado de cuenta, Historial gráfico e Historial de clases.
- **`clases.html`** – Mis Clases: listado de clases matriculadas con días, hora, profesor, campus, aula, modalidad (Presencial/Virtual) y la tabla de notas del período (parciales y promedio).

## Cómo verla

Abre `index.html` en el navegador (idealmente con la vista móvil de las DevTools) o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```
